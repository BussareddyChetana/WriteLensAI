# WriteLens AI — AI Content Detection Platform

> **Tagline:** Know Who Wrote Your Words.

WriteLens AI is a production-ready Final Year Machine Learning project designed to detect whether written content is produced by a human or generated by Artificial Intelligence. 

Instead of simple binary labels, WriteLens AI provides comprehensive explainable AI insights, sentence-by-sentence risk evaluation, stylometric writing statistics, experimental AI source estimations (ChatGPT, Gemini, Claude, Llama, Mistral), and downloadable publication-grade PDF audit reports.

---

## 🌟 Key Features & Objectives

WriteLens AI addresses four core analytical questions:
1. **Classification:** Is this content Human-written or AI-generated?
2. **Confidence Score:** How mathematically confident is the prediction model?
3. **Stylometric Rationale:** Why was this prediction made? (Evaluates sentence length variance, transition word density, Type-Token Ratio, and clause balance).
4. **AI Source Estimation (Experimental):** Estimates match probabilities across 5 popular AI models (*ChatGPT, Gemini, Claude, Llama, Mistral*) with explicit disclaimers.

### Platform Capabilities:
- **Multi-Format Processing:** Paste text directly or upload `.txt`, `.pdf`, or `.docx` documents.
- **Sentence-Level Inspection:** Highlights individual sentences with color-coded risk levels (*High AI Risk, Moderate AI Risk, Human Pattern*) and specific structural reasons.
- **PDF Report Generator:** Generates downloadable audit PDFs using ReportLab.
- **Authentication & User Dashboard:** User registration, login, profile management, and dashboard with detection statistics.
- **History & Search:** Store, filter, search, review, and manage previous analysis records.
- **Admin Management Panel:** View system-wide metrics, user directory, aggregate AI vs Human ratios, and ML algorithm comparison metrics (*Logistic Regression, Linear SVM, Random Forest*).

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js
- **Backend Framework:** Python 3.10+, Flask 3.0+
- **Database & ORM:** SQLite, SQLAlchemy (Flask-SQLAlchemy, Flask-Login)
- **Machine Learning:** Scikit-learn (Logistic Regression, Linear SVM, Random Forest)
- **Natural Language Processing:** NLTK, spaCy compatible preprocessor
- **Feature Extraction:** TF-IDF Vectorization (1-2 n-grams) + Stylometric Feature Vectors
- **Document Processing:** PyPDF2 (PDF), python-docx (Word DOCX)
- **PDF Report Generation:** ReportLab
- **Model Storage:** Joblib

## 🚀 Execution & Quick Start Guide

### Step 1: Install Python Requirements
Open terminal in the project directory and install dependencies:
```bash
pip install -r requirements.txt
```

### Step 2: Train Machine Learning Model
Train Logistic Regression, Linear SVM, and Random Forest models on the dataset, evaluate accuracy metrics, and select the best model:
```bash
python train.py
```
*(If `dataset/ai_vs_human.csv` is not present, `train.py` automatically generates a sample dataset so model training succeeds out-of-the-box).*

### Step 3: Run Application Server
Launch the Flask development application server:
```bash
python run.py
```

### Step 4: Open Web Browser
Navigate to:
```
http://127.0.0.1:5000
```

#### Default Administrator Credentials:
- **Username:** `admin`
- **Password:** `admin123`
